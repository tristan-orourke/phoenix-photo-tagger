# Implement Skill

Execute implementation from an existing plan document.

1. Read the plan document specified in $ARGUMENTS
2. Identify the specific phase or section to implement
3. Write the actual code immediately - do NOT create another planning document
4. Start writing tests/code within the first 2-3 tool calls
5. After implementation, run relevant tests to verify the changes
6. Fix any test failures before completing

Do NOT enter plan mode. Do NOT explore the codebase extensively before writing code. Focus on direct implementation.
